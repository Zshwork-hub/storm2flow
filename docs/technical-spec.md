# storm2flow 小流域山洪灾害预测工具

## 可执行技术规格（MVP-1.0）

**文档状态**：开发基线；P4 授权的合成验证和本机性能评估已完成，真实案例验收待补数据
**原始方案**：[初步制定的可实施方案.md](./初步制定的可实施方案.md)
**目标用户**：基层水利员
**运行环境**：Windows、QGIS 3.44.14（本机已安装版本）
**结果定位**：设计洪水初步筛查，不作为防洪调度、工程设计或正式预警依据。

本文档是开发约束。文中的公式、单位、数据结构、错误处理、测试和验收条件必须先实现并通过验证，再扩展其他功能。

## 1. MVP 范围

### 1.1 必须实现

1. 读取一个投影坐标系的 DEM 和一个控制断面点。
2. 对控制断面进行河网吸附，生成单一出口点。
3. 完成填洼、D8 流向、汇流累积、河网提取和流域划分。
4. 提取流域面积、主河道长度、主河道平均比降，并显示原始值和人工修正值。
5. 接受手动输入或内置数据源提供的设计面雨量过程。
6. 采用初损—稳损模型计算净雨过程。
7. 采用 Gamma 瞬时单位线计算洪水过程线和洪峰流量。
8. 输出 CSV、PNG、GeoPackage 和 Markdown/HTML 报告。
9. 对输入、单位、结果单调性和水量守恒进行检查并生成警告。

### 1.2 MVP 不实现

- 实时降雨和实时预报；
- 二维淹没模拟；
- 多流域批量计算；
- 数据库和在线服务；
- 未经本地水文手册确认的全国通用经验公式；
- 自动把多个方法结果合成为“正式推荐值”。

## 3. 坐标系、单位和数据约束

### 3.1 坐标系

- DEM、控制断面和输出流域必须使用投影坐标系，水平单位为米。
- 输入 DEM 为经纬度坐标系时，计算前必须重投影到用户指定的米制投影坐标系；不得直接用经纬度计算面积、长度或比降。
- 所有输入图层在处理前统一到 DEM 的水平 CRS；转换过程写入日志。
- 高程单位统一为米；降雨量统一为毫米；时间统一为小时；流量统一为 m³/s。

### 3.2 DEM 质量检查

必须检查：

- CRS 是否存在；
- 像元大小是否为正；
- NoData 是否存在且被正确掩膜；
- 高程是否包含无效值；
- DEM 是否覆盖控制断面；
- 水平像元大小是否超过 100 m（超过时给出低分辨率警告）。

### 3.3 输入规模

- 默认适用流域面积：0.1—1000 km²；超出范围只允许在用户确认后继续。
- 面积、长度、比降均必须为正数。
- 比降以无量纲小数表示，例如 5% 写为 `0.05`。

## 4. 总体处理流程

```text
输入检查
  → CRS 统一和 DEM 质量检查
  → 填洼
  → D8 流向
  → 汇流累积
  → 河网提取
  → 控制断面吸附
  → 流域划分
  → 主河道追踪和参数计算
  → 设计雨量过程
  → 初损—稳损产流
  → Gamma 瞬时单位线汇流
  → 结果检查
  → CSV/PNG/GeoPackage/报告输出
```

每个步骤都必须生成可复用的中间文件。失败时保留中间文件、错误信息和输入参数，禁止静默继续。

## 5. DEM 和流域参数模块

### 5.1 河网提取

河网提取阈值必须由用户设置，默认值不再固定为 1000。默认阈值按流域面积和 DEM 像元数给出建议值，用户可以预览河网并调整。界面必须显示阈值变化对河网的影响。

### 5.2 控制断面吸附

输入控制断面点后，在用户设置的搜索半径内寻找最大汇流累积栅格或河网像元。吸附结果必须显示：

- 原始点坐标；
- 吸附后点坐标；
- 偏移距离；
- 吸附是否成功。

超过搜索半径时停止计算并要求用户重新选点。

### 5.3 流域面积

在投影 CRS 下，使用流域栅格有效像元面积计算：

```text
area_km2 = 有效像元数 × 像元面积_m2 / 1,000,000
```

输出面积必须保留至少 3 位小数。

### 5.4 主河道长度

河网必须先矢量化或建立栅格邻接关系。主河道定义为：从控制断面向上游追踪后累计长度最大的连续路径。长度计算必须考虑横向、纵向和对角线距离：

```text
横向/纵向距离 = 像元边长
对角距离 = 像元边长 × sqrt(2)
```

河网总长度可以作为辅助输出，但不得代替主河道长度。

### 5.5 主河道比降

沿主河道按距离采样高程，生成距离—高程纵断面。默认比降为首尾高程差除以主河道长度；同时计算线性回归比降作为质量检查。局部高程异常必须使用明确的中值滤波或稳健回归处理，并记录处理方法。

不得按高程数值排序来代替河道上游到下游排序，不得在代码中硬编码 30 m 分辨率。

### 5.6 人工复核

自动提取的面积、长度、比降必须在界面中可编辑。用户修改后，报告同时保存：

- 自动值；
- 用户修正值；
- 修正原因（可选）；
- 最终用于计算的值。

## 6. 设计暴雨模块

### 6.1 输入模型

每个雨量过程必须包含：

```json
{
  "time_step_h": 1.0,
  "duration_h": 6.0,
  "rainfall_mm": [12.0, 35.0, 58.0, 42.0, 20.0, 8.0],
  "source": "manual",
  "return_period_y": 20
}
```

`rainfall_mm` 表示每个时间段的雨量，不表示累计雨量。数组长度必须等于 `duration_h / time_step_h`，允许存在浮点舍入误差但必须在加载时校验。

### 6.2 图集数据

图集文件必须记录：

- 数据来源、地区和版本；
- 原始图件或出版物信息；
- 坐标系和网格分辨率；
- 历时和重现期；
- 参数类型及单位；
- 插值方法；
- 有效范围。

网格外坐标默认禁止外推。点面系数和雨型必须带有来源和适用地区；示意经验公式只能用于演示数据，不能作为默认正式参数。

### 6.3 点面换算

点面系数必须由三种方式之一提供：

1. 本地暴雨图集查算；
2. 用户手动输入；
3. 已登记、带来源和适用范围的地区经验公式。

程序必须在报告中记录实际使用的来源和公式。

### 6.4 雨型和时间步长

雨型由显式数组定义，不使用 `np.ones(duration_h)` 这类把小时数直接当数组长度的实现。10 分钟、1 小时、6 小时和 24 小时雨型必须分别提供合法的时间步长和数组长度。

雨型数组必须满足：

- 每个比例大于或等于 0；
- 比例总和等于 1（允许 1e-8 误差）；
- 峰值位置和雨型名称写入报告。

## 7. 产流模块

### 7.1 默认模型

MVP 使用初损—稳损模型：

```text
初损阶段：先扣除 Ia，不产生净雨
初损满足后：净雨_i = max(0, 毛雨_i - f × Δt)
```

其中 `Ia` 单位为 mm，`f` 单位为 mm/h，`Δt` 单位为 h。

### 7.2 输入检查

- `Ia >= 0`；
- `f >= 0`；
- 降雨量不得为负；
- 时间步长必须大于 0；
- 空数组、NaN 和无穷值必须拒绝。

### 7.3 输出和守恒

必须输出每个时段的：

- 毛雨量；
- 初损扣除量；
- 稳损扣除量；
- 净雨量；
- 累计毛雨和累计净雨。

产流体积公式为：

```text
volume_m3 = total_net_rain_mm × area_km2 × 1000
```

`net_rain_duration` 不作为隐藏参数。若要截断雨量过程，必须显式指定截断时间并在报告中说明。

## 8. Gamma 瞬时单位线模块

### 8.1 参数定义

Gamma 单位线使用形状参数 `n` 和尺度参数 `K`。MVP 的数学实现允许 `n > 0` 的非整数值，使用 Gamma 函数计算，不使用 `range(n)`。

单位响应函数定义为：

```text
u(t) = t^(n-1) × exp(-t/K) / (K^n × Γ(n)),  t > 0
```

对应 S 曲线为单位响应函数的累计积分。数值实现必须使用 `scipy.special.gammainc` 或等价的经过验证的方法。

### 8.2 参数来源

`n`、`K` 可以来自：

1. 用户手动输入；
2. 本地水文手册公式；
3. 率定结果（后续版本）。

经验公式必须配置地区、来源、单位和适用范围。MVP 不得把示例系数视为全国通用公式。

### 8.3 时段单位线

给定时间步长 `Δt` 后：

```text
U_j = S(t_j) - S(t_j - Δt)
```

`U_j` 是每个时间段的无量纲响应比例。单位线截断时间必须持续到累计响应至少达到 0.999，并在测试中验证单位线总和接近 1。

### 8.4 卷积和单位换算

对于每个时段净雨 `R_i`（mm）：

```text
Q(t) = Σ [U(t - iΔt) × R_i × A / (3.6 × Δt)]
```

实现后必须通过水量守恒校验：洪水过程线积分对应的体积与净雨体积的相对误差小于 1%。若数值截断导致误差超限，延长单位线计算时间并给出警告。

### 8.5 洪峰输出

输出：

- 洪峰流量；
- 洪峰出现时间；
- 洪水过程线；
- 洪水总量；
- 单位线参数和截断误差。

## 9. 对比方法

推理公式和地区经验公式只作为辅助结果。推理公式必须使用与汇流时间相匹配的设计降雨强度，不得使用整场平均雨强代替。地区经验公式必须从暴雨模块接收实际设计雨量，禁止硬编码 `P=100`，重现期必须真正参与计算。

如果缺少当地公式或适用参数，界面应禁用该方法，而不是输出示意结果。MVP 的正式主结果仅为 Gamma 单位线法。

## 10. 结果检查和报告

### 10.1 自动检查

必须检查：

- 输入参数和单位完整；
- 流量、净雨和体积非负；
- 净雨不超过毛雨；
- 洪水体积与净雨体积守恒；
- 单位线响应和 S 曲线单调；
- 重现期增大时，设计雨量和洪峰是否保持非递减；
- 图集坐标没有越界；
- 方法和参数来源完整。

检查失败时分为：

- **错误**：停止计算；
- **警告**：允许导出，但报告显著标注；
- **提示**：不影响计算，仅供参考。

### 10.2 输出文件

每次计算生成独立目录，至少包含：

```text
result/
├── parameters.json
├── rainfall.csv
├── runoff.csv
├── hydrograph.csv
├── peak_flows.csv
├── hydrograph.png
├── basin.gpkg
├── intermediate/
└── report.html
```

报告必须包含输入来源、CRS、自动值和修正值、公式、参数、警告、版本和计算时间。

## 13. 测试和验收

### 13.1 单元测试

- CRS 检查能够拒绝缺少 CRS 的 DEM；
- 经度坐标 DEM 不会被直接用于面积计算；
- 初损、稳损和净雨满足不等式约束；
- 空雨量过程输出全零过程线；
- Gamma 单位线支持 `n=2.5` 等非整数参数；
- S 曲线单调递增并趋近 1；
- 单位线总和误差小于 1%；
- 洪水体积守恒相对误差小于 1%；
- 图集越界、缺字段和错误数组长度能够被拒绝。

### 13.2 合成数据验收

合成 DEM 必须使用米制投影 CRS、固定随机种子、明确出口点和理论参数。验收指标：

- 面积相对误差小于 5%；
- 主河道长度相对误差小于 10%；
- 主河道比降相对误差小于 10%；
- 产流体积误差小于 1%；
- 汇流体积守恒误差小于 1%。

### 13.3 集成验收

使用至少一个文献案例和一个人工构造案例，记录数据来源和人工计算基准。不得用“趋势合理”代替数值验收。至少比较：

- 洪峰流量；
- 洪峰时间；
- 洪水总量；
- 参数和输入雨量；
- 异常和警告是否正确出现。

### 13.4 用户验收

邀请 2—3 名基层水利员完成以下任务：加载 DEM、选择断面、复核参数、输入雨量、运行计算、导出报告。目标是普通用户无需打开 Python 控制台即可完成流程，正常数据的计算时间小于 5 分钟。

P3 界面使用 `qgis.PyQt` 与 QGIS 原生控件以代码构建。输入快照通过 `QProcess` 交给 QGIS 自带 Python；核心模块不访问 Qt 控件。空间预览与水文输入独立，结果回传时校验空间输入是否变化。导入超出控件范围或精度的参数时拒绝，不静默改值。复核后的显示参数用于水文计算，自动原值同时保留。

当前进度条只显示运行/结束状态，不估算完成百分比。完整桌面安装交互和基层用户操作仍属于试用验收，操作步骤见仓库 `docs/qgis-plugin-guide.md`。

P1 当前采用坐标输入出口，`outlet_crs` 必填，坐标顺序为 x/y。经纬度 DEM 必须提供 `processing.target_crs` 的米制投影；重采样为双线性，覆盖区外按 NoData 排除。NoData 邻接单元按开放排水边界处理。

主河道长度严格在 `streams & watershed` 范围内求最长路径，阈值使用贡献像元数。未填写 `stream_threshold_cells` 时采用 `max(2, floor(valid_cell_count×0.005))` 作为待复核建议值。平坦区向下坡和边界种子传播，无环且可重复。比降采用填洼后高程，保存原始/处理后纵断面供人工复核；当前不自动平滑剖面，后续界面应允许人工修正参数。

P2 导出的流量为时段平均流量，时间字段为 `start_time_h`、`end_time_h`，峰值时间报告为所在区间。洪量统一按 `ΣQ×Δt×3600` 计算。不得对这些平均值使用梯形积分而改变水量口径。

## 15. 当前已明确修复的原方案问题

- 不再使用经纬度坐标直接计算面积和长度；
- 不再按河道像元数量近似主河道长度；
- 不再按高程排序估计河道比降；
- 不再硬编码 30 m 分辨率；
- 不再把浮点小时数直接当作数组长度；
- Gamma 单位线支持非整数 `n`，消除 `range(n)` 运行错误；
- `net_rain_duration` 不再作为未使用的隐藏参数；
- 推理公式不再使用整场平均雨强替代汇流时间雨强；
- 经验公式不再使用固定 `P=100`；
- 合成 DEM 要求米制 CRS 和固定随机种子；
- 测试增加水量守恒、单位线归一化和边界条件；
- 主结果和辅助方法结果分开，不自动生成缺乏依据的推荐值。
