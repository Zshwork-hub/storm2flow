# QGIS 插件试用说明（0.2.0）

当前仅验证 QGIS 3.44.14（Windows）。这是合成数据测试过的试用插件，真实案例精度和基层用户试用尚未验收。

## 安装

1. 打开 QGIS 3.44.14。
2. 选择“插件 → 管理并安装插件 → 从 ZIP 安装”。
3. 选择 `dist/storm2flow-0.2.0.zip` 并安装。
4. 在插件列表中启用“storm2flow 小流域设计洪水”。
5. 从“插件 → storm2flow”菜单或工具栏启动。

ZIP 内只有一个顶层 `storm2flow/` 目录；`__init__.py` 和 `metadata.txt` 在该目录中。不要把整个 Git 仓库直接压缩作为插件安装包。

开发者可在仓库根目录执行：

```powershell
.\tools\run-qgis-python.ps1 -PythonArguments @('tools/build-plugin.py')
```

无需安装 rasterio 或 WhiteboxTools。启动时检查 NumPy、SciPy、Matplotlib、GDAL 是否能在 QGIS Python 中导入。

## DEM 自动模式

1. 在“流域与出口”页输入流域名称，选择 DEM。
2. 输入出口坐标及其 CRS，或点击“在 QGIS 地图上选择出口”后在地图上点选。地图点使用当前画布 CRS，坐标顺序为 x/y。
3. 如果 DEM 是经纬度坐标系，勾选重投影并选择当地适用的米制投影 CRS。
4. 设置吸附半径与河网阈值。阈值为贡献像元数；0 表示由程序提出建议值。
5. 在成果页选择已有的保存目录，再点击“提取并预览流域参数”。此阶段无需填写暴雨。
6. 查看出口偏移、回归比降和警告，在成果页加载流域、主河道、原始/吸附出口图层。空间预览目录含主河道纵断面 CSV。
7. 必要时修改面积、长度、比降，勾选参数确认。修改 DEM、出口、CRS、吸附半径或河网阈值后，必须重新提取；修改提取值后必须重新确认。
8. 在“暴雨与产流”页填写每时段雨量、步长、重现期、初损、稳损及暴雨来源。
9. 在“汇流与成果”页填写 n、K 和参数来源，点击“计算设计洪水并导出”。

界面显示的默认损失和单位线值是示例值，必须核对本地参数。结果采用时段平均流量，峰现时间表示所在区间。

## 手动参数模式

切换为“手动流域参数”，输入面积、主河道长度和比降，填写暴雨与单位线参数并确认。该模式不虚构空间边界，输出报告会提示未执行 DEM 提取。

可通过“导入已有参数 JSON”复用配置。导入值超出界面范围或精度时会明确拒绝；不会静默截断或取整。更高精度的配置可使用 CLI。

## 运行与成果

计算在独立 QGIS Python 进程中运行，窗口保持响应。进度条显示运行状态；当前不表示已完成的百分比。“取消计算”会终止进程并保留已产生文件，关闭运行中的窗口前需先取消。

每次作业生成独立目录，不覆盖以前成果。保存目录中的 `.storm2flow-jobs/` 含本次输入快照与绘图缓存；空间预览和设计洪水成果单独存放。

计算完成后可打开 HTML 报告或加载空间成果。警告、参数来源、自动值和人工覆盖值均应复核后使用。

## 当前限制

- 暴雨、初损稳损、n/K 参数以手动输入为主，未接入正式本地图集与率定数据。
- NoData 邻接单元采用开放排水边界；流域接触边界时需检查 DEM 覆盖。
- 大 DEM 性能、真实洪水误差和基层用户操作仍需后续验收。
- 自动预览值按界面显示精度四舍五入；计算使用用户确认的显示值，同时保留自动提取原值。
