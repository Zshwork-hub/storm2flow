## 本阶段范围

当前用户没有真实案例资料，授权先完成合成验证与性能评估。真实洪峰误差不作验收结论。

原方案引用的微信文章未能获取完整输入和结果；A/B 镇面积本身不足以复现案例。原方案中的雨量、n/K、经验公式系数和示例结果不能充当独立真实基准。

## 独立合成基准

- 产流：手工指定初损和稳损扣除后的净雨序列。
- n=1：指数响应闭式解。
- n=2：整数 Gamma 闭式解。
- n=2.5：对概率密度独立数值积分，不调用产品所用的 `gammainc`。
- 参考卷积：逐项标量求和，不调用产品使用的 `numpy.convolve`。
- 地形：规则倾斜平面，预先指定理论面积、最远河道路径长度和比降，覆盖方形/非方形像元。阈值为 1，测试最长路径几何；不能用该阈值作为真实地形默认值。
- 趋势：同雨型、逐时段嵌套增加雨量，在固定损失和单位线参数下检查洪峰非递减；不代替真实重现期统计检验。

验收阈值：空间面积误差 <5%，主河道长度和比降误差 <10%；水量误差 <1%。水文解析/积分参考的逐点流量差 <1e-8 m³/s、洪峰相对误差 <1e-8、峰值区间起点差 <1e-10 h。

产品使用时段平均流量输出，参考采用相同的区间起点离散响应假设。本验证不能证明区间内均匀降雨连续模型的精度，也不能证明单位线和损失参数适用于某真实流域。

## 本机性能

```powershell
.\tools\run-qgis-python.ps1 -PythonArguments @('tools/run-validation.py', '--output', 'results/p4-new-run', '--sizes', '128', '256', '512', '1024', '--repeats', '2')
```

每个重复启动新 Python 子进程。计时包含 DEM 分析、产流汇流、栅格和矢量写出、CSV/PNG/HTML 输出；另记包含依赖启动和输入生成的总进程耗时。

DEM 为 30 m 正方形像元，1024² 像元覆盖约 943.72 km²。峰值工作集由 Windows 进程信息读取，包含输入生成和依赖开销。少量重复只报告实测范围，不提供统计置信区间。

复杂平坦区、NoData、大洼地和地形噪声会改变时间与内存。规则倾斜面上的结果不能承诺所有同尺寸真实 DEM 均在 5 分钟内完成。

输出目录必须不存在。结果包含 JSON、CSV、Markdown 报告、日志及各次完整计算成果，失败/超时同样记录，不剔除不利结果。

运行开始时保存输入和代码 SHA-256 快照。归档工具核对产品源文件是否仍与测量时的 Git 提交一致，只归档报告、小型 JSON/CSV 和日志，不把大型合成 DEM 提交到仓库：

```powershell
.\tools\run-qgis-python.ps1 -PythonArguments @('tools/archive-validation.py', 'results/p4-new-run', 'docs/validation/new-run')
```

首轮 2026-10-08 性能测试早于源快照功能；其产品源文件已与测量时提交逐项核对，验证脚本的校验值标记为归档时，而不假称运行开始时校验值。

## 后续真实案例资料

资料应包含 DEM 与 CRS、高程单位、出口位置与 CRS、逐时段面雨量、时间步长、损失参数、n/K 及参数来源，以及独立洪峰/洪量/峰值区间基准。模板位于 `examples/validation/real-case-reference.template.json`，null 字段必须补齐后才能验收。

必须先对齐基准与产品的流量语义、时间步长、面积、雨量单位和事件范围；实测瞬时洪峰不能直接当作时段平均洪峰。留存源文件及校验值，并分开报告洪峰相对误差、洪量相对误差和峰值时间差。不得为了通过案例而复用待验算法输出作为参考。
